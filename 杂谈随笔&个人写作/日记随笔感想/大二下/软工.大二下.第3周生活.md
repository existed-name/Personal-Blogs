# 3.16.星期1
## 1、对于`听歌&效率`的思考
**(1)总结**

分析有点啰嗦，先奉上想到的结论

* `边听歌边做任务`的根本目的是`想要听歌`，有`同时做几件事很赚`的心理、有`不承认自己被听歌分散注意力`的心理、`奖励机制`的心理、营造氛围等等。同理`边听小说/边看电视`……

* `听歌干扰效率`这件事，感觉因人而异，有的人就是边听歌边做事更好更快，有的人就是需要避免一丁点干扰。不过还是不能否定: 听歌会分散注意力

* 缺少一点激情/提不起劲儿、心情不太好的时候，可以边听歌边做任务；能够进入比较好的沉浸状态，那就不要再听歌之类的分散注意力了

**(2)分析**

我以前有边听歌边写作业的习惯，我妈也边化妆/洗碗边听小说，今天写看书笔记的时候我的手机就是外放的

我以前也想过听歌对效率的影响，不过当时我发现写作业 + 听歌还挺舒服的，而听歌 + 简单任务好像也没什么影响。然而今天我感觉干扰稍微有点大，于是就细想了一番

听力发挥作用时，一部分专注肯定会转移到听力上，进而放到手上、尤其是脑子思考的专注就变少了，那么应该是会降低效率的。但如果是体力占比很大、不怎么需要动脑的事情，比如锻炼、家务，那么这部分干扰可以忽略，因为**重复性比较强、不需要太多专注力**

但是又怎么解释我边写作业(那还是初高中)、边听歌，效果依然不错?我的想法是，写作业在一定程度上有思维的重复(套路/模板)，但这个重复性可以忽略，因为大部分都需要动脑；更可能是**接触到喜欢的歌后，更兴奋了、氛围更好、更容易沉浸到自己的世界**，促进思考，抵消听觉分散注意力，如果再习惯了听歌 + 写作业，那么分散的注意力就很小了，从而起到部分提高效率的作用

然而，写题终究是把思维限在知识点范围里面，如果进行更广的思考，比如看书后的心得感悟，那么过于发散的问题，脑子首先回忆/遍历已知内容，然后到处想可不可以找到1个点，把抽象变成可以描述的语言。于是在这个“比较艰难”的过程中，**听歌更加拉扯自己的注意力，更难让自己接近具体化语言**

而且最有意思的是，我在做自己的事情时，把歌加进来，其实并不是为了提高效率——这只是间接的目的，真正的、被心理因素隐藏的目的，就是听歌本身。也就是说，平常没什么时间、也不会想着听歌吧(最好的状态肯定就是沉浸一件事，谁会想要引入干扰项)，而某个时候，觉得这件事好像很稳、拿捏了，于是就想着听歌吧，**本质是为了听歌，`边做事边听歌`只是接口**，也是想要`一举两得`的贪心

不过，终究还是需要听歌——尤其是感觉缺了点什么、差点氛围/激情，的时候，这个时候用听歌作为催化剂，就可以比较好的拉回效率

我在想，几乎没有人会只听歌，不干其他事情——甚至走神吧，这样就能专心地只干一件事了😄只能说，**因为大家都很忙，没有人会为了听歌而听歌，听歌、听小说、看电视这种，都成了做任务的附属奖励**(又找到1个`奖励机制`的心理因素)……



# 3.17.星期2
## 1、情节性小说、技术文档、技术博客之间的替代关系
喜欢故事情节性强的书——那自然就是小说了，也自然不喜欢比较枯燥的散文、诗集等等。然而我还没研究过自己对看论文的反应(初高中阅读题除外)，以前查资料曾经翻过一些论文，不过带有比较强的目的性，我不确定论文本身对我有没有吸引力。从严谨实验/测试、推导的论文退一步，像专业书籍这种，不过我比较排斥(不知道是不是看教材太坐牢，还是自己太菜，应该都有)，那再退一步就是技术性强的文章(技术文档)，我发现官方文档我也能看，也没有心理上的排斥；而对于偏向“科普”的技术博客/图文讲解，我就更有好奇心了(尤其会有涨知识的倾向)

于是我想: **可不可以用看技术文档替代看书**?

以前我是刷知乎/公众号，我分析是自己`对文字阅读的渴望`，于是替换成了看书。那么反过来替换应该也是可以的，比如我是看文档学习——如果去掉`赶进度`的念头，用`涨知识`、`阅读文字`的心理来驱动自己，那就跟看书差不多了

然而技术文档需要频繁动脑、可能要实操，如果正反馈不够，可能会有一点阻力、中断；看书(情节性小说)则尽量梳理情节、可疑点(带脑子看)，但毕竟是小说，就算不是网文，也容易上头，不过上头之后可能是空虚/混沌，很需要读书笔记输出信息、整理脑子。此外，科普性质、更大众化的技术博客直接刷，跟看小说一样不带停的

所以，我觉得**看书(情节性小说)、技术博客(知乎/公众号)可以互相替代**，因为它们有足够的吸引力，然而，**看技术文档学习只能在一定程度替代看书、技术博客**，因为技术文档始终要更难啃一点，我总会有看累的时候，总会有被前两者吸引的时候。那么**比较好的搭配**是文档 + 博客、文档 + 小说，就凑成了文字阅读 + 学习 + 放松。而我`用技术文档替代看书`的想法，太过单调，不可能一直学下去，看技术文档只能削减我看书的欲望，却不能消灭之

(: 然而这只是从我这个个体进行的分析……


## 2、打球打输的反思
听到楼下打球的声音，又兴奋地冲下去、参一个，不过是双打，体验感不太好，站了快2个小时，终于有单打的机会，我估计对方实力比我低一些、也没有步法，然而等我“大显身手”的时候，发现自己频频打杆、没接到球、步法杂乱且启动太慢/意识降低、不如之前的状态，轮着两三局都是“差一点点”，心理挫败感十足、不应该啊，然而调整心态，再来1局，还是失败，只能频频捂脸叹气“我靠”以及伸手示意“抱歉”，气自己不应该打不过实力不如自己的同学

之后我再反思: 

1. 我可以估计任何人的实力、跟自己比较，但**不应该把情绪加进评估**，比如我确实比对方实力强一点，但我附带了优越感(轻视对手)、挫败感(生气)等等情绪上来，进一步降低我的优势

2. 而且也有实力估计出错的情况，仅从一点表象分析，怎么能说明我一定更强(但这个不代表不应该分析对手)

3. **实力 ≠ 成败**，就算是小说也经常有配角越级挑战的操作，更何况现实中下象棋、打球等等。实力只能是1个客观、相对的指标，是胜率，而赢的因素有太多

4. 本质还是实力不够，**菜就多练**(更何况步法才入门几个星期)，鉴于双打不太适合自己，以后就尽量单打局()练练技术

5. 跟陌生人打球的一大要命之处就是**紧张**(潜意识里面总会有点)，过度在意每一颗球的得失。慢慢调整、习惯吧，练技术而已、不是来拿奖的，大大方方承认自己打不过别人

6. 希望对方不要觉得我球品不太好😂(: 情绪的控制……

# 3.21.星期6
## 1、预判高铁的停车点
> 这个本来是寒假结束回学校的事情了，不过还是回忆一下，有意思

1. 高铁始终会开过地标，大概2米

2. 人群会在地标排队，但最后一定会往偏移的那个位置走

3. 于是我们可以提前预判那个位置，这样就可以“排到最前” => 只需要确定高铁来的方向

4. AI说`高铁通常倒着开进站` => **最后1号车厢(号码更大的)先进站**

5. 车厢号码顺序 = 地标顺序 => **高铁进站方向 = 地标变大的方向**

6. 综上，**站在自己的地标、往地标号码变大方向、走2m的位置等高铁**🤣


## 2、闹钟
20min，午觉又没睡着，闹钟响了后，想，干脆再咪一会儿，有一点感觉，但不多，算了，起立……

突然想起，起床闹钟响后，比睡前更想睡觉、更睡得着，所以我想，会不会睡觉前先定闹钟，睡几分钟让闹钟打断一下，然后继续睡，会更快睡着?🤔(相当于用闹钟`催眠`)

> 根据自身经历分析🧐

1. 睡着，进入睡眠周期:
   
* **浅度睡眠**被吵醒，睡意会瞬时减少，然后大脑根据自己的情况调整睡意——潜意识想继续睡(比如现在躺在床上)，就增加睡意；有任务要做(包括上厕所)，大脑强制减少睡意
* **深度睡眠**被闹钟吵醒，自然还很想睡，而且这时闹钟起阻断作用还不利于睡眠质量

2. **睡前，看状态**:
   
* 困的话直接就可以睡，根本不需要再定个临时闹钟；
* 有点睡意，刚进入浅睡眠，然后给闹钟一惊，但因为知道自己要睡觉 + 全身放松 + 不需要起床，利用大脑增加的这波睡意，恢复之前的浅睡状态，再过渡到深睡；
* 不困，睡了10多20分钟(甚至更久)还是没什么感觉，这个时候才该起床稍微活动(喝点水/上厕所之类的)，换换状态继续睡(以前有不少这样的经历)
* 已经形成几分钟入睡的生物钟了，那也没必要定闹钟`催眠`了

3. **整理**:
   
* 困、有稳定生物钟，不需要用闹钟`催眠`
* 其他状态可以试一下，定个10~15min的闹钟(只振动、无铃声)，浅度睡眠醒了，闹钟一关，倒头继续睡，不影响(我是把手机放在手指旁边，乱按也可以按到[doge])；一直没睡着，起床上厕所、换个状态

4. **漏洞**:
   
* 浅睡，尤其是刚躺床上，刚迷迷糊糊那个时候，如果闹钟响起，把人的警觉性/兴奋性拉满，结果反而睡不着了
* 那么，还是问AI吧😂(它说有一定道理，但是只能偶尔试一下，用多了可能养成习惯干扰睡眠；这里就不附图了)


## 3、美化丑陋 vs 袒露丑陋
锻炼频繁，加上升温，汗水多，偶然闻到鞋子汗臭，并且正好在拼多多看快递，它给我推了1个除臭喷雾(这刁钻的算法)……

于是我在想，鞋子臭，如果上喷雾，那么肯定就香了，别人闻得出来、自然知道自己是有意的，进而可能知道鞋子臭；如果不喷，那么肯定就是赤裸裸的气味。**对于后者，别人会反感；前者，别人不会欣然接受**(因为`不太正常`、或者说`不自然`)，**但不会排斥、还可能会理解**

进而分析`美化丑陋 vs 袒露丑陋`: 

1. 什么是`丑陋`: 这里指的是`人们讨厌的东西`以及`缺点`(当然，不够严谨~~~)

2. 什么是`美化`: 通过手段，把大家讨厌的，包装成不讨厌、甚至喜欢的(可以限时、不限时)

3. `袒露`: 不加掩饰，把`不好/缺点`大大方方地展示出来

4. 我觉得主要是`主观性、客观性`的问题
* 为什么要`美化`: 主观上不舒服啊，客观评价也不太好啊
* 为什么又`袒露`: 容不得主观、必须客观，或者我就是喜欢这样(这也是主观)
* 于是，历史科技经济社会等等领域，必须`袒露`；能改的缺点/不足，一定要`美化`；而性格坦率大方的，就`袒露`出来，作为个性好了……

当然，我还是拍下了拼多多推给我的喷雾🐶(我不理解，买羽毛球相关商品——没买球鞋——也可以推算到这一步)
