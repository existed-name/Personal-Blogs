# (一)3.30.星期1
## 1、脱外套困境🥶
前几天太阳 + 升温，于是防晒衣 + 短袖，这几天突然下雨降温，先换成厚一点的外套，但还是有点遭不住，想把短袖换成长袖，发现: 我现在外套 + 短袖，有点冷，如果脱掉外套，那么冷得多、难受，但是我不脱外套，又怎么换衣服😅

于是就构思了这个困境: 1个人处在室外寒冷环境，现在需要把里面的衣服换成更厚的衣服，他必须脱掉外套才可以执行这个操作，然而一脱掉外套他可能会冻伤/感冒，但不换衣服他就不能长时间保暖，那么他应该怎么做🤔

我的想法是🤔可以先锻炼会儿，加热身体后，换衣服；另外直接换衣服，再热身，像贝爷那样跳进河里、起来之后疯狂热身，应该也可以……

不过为什么不换更厚的外套


## 2、无奈的博弈🤨
**(1)进场**

今下午有1讲`创新创业基础`，前2次没去都被点了，这次不得不召唤代课了。然后老师点名，代课大惊给我发消息，说老师让我放学找她

我也大惊，先垫1些给代课，心想让代课去对线老师算了。后来又想，要是老师记住的是代课，不是我，那我之后去上课会不会炸了😅而且变数太大，怕把握不住

于是我问代课老师对他印象深不深、他的外貌特征(衣服/眼镜……)，放学前赶到了教室，在关了门的教室外面徘徊，我也在想，会不会其实老师又忘了这件事，我跟代课直接润掉算了，但又想这样态度不太好😵

提前放学的班级涌出来，然后前门开了，我挤过蜂拥而出的人群(以及一脸懵逼的神情)，还好老师低头收拾东西，没注意我，我直接走近讲台

**(2)对线**

“老师你找我?"

"你是……"(翻花名册；老师看起来挺温柔)“哦，你是xxx"( 大喜，他对我、代课没有印象，或者忘了

“我是yyy"( 大喜 * 2，竟然还有难兄难弟，被点了几次没来😂

"对对，你2次都没来是怎么回事……"( 手指花名册的2个×

“……”( 心头一紧，总不能说我躲在寝室写代码吧

"下次记得要来……"( 大喜 * 3，还好没追究 )

我点头，她继续收拾东西、准备撤退，我靠，这么好说话嘛

然后装作求教的学生一样，"沉着谦逊"地问些想知道的问题(考核啊作业啊分组啊之类的)、顺便套套近乎，嘿，老师一下又精神了，谈了不少课程相关事情、手跟着一起动，看来对教课热情十足，从这个方面切入可以降低老师的防备，并且转移注意力

"对了，上课回答问题可以消1次缺勤……"( 牛逼，我后来知道室友翘1次，再去1次，回答1次问题，继续翘🤣

从进来到出去，3min……

**(3)回顾**

1. 没被细究缺勤原因，大部分是运气好
	* 刚好遇到比较好说话的老师
	* 老师可能也急着走
	* 老师也懂，不想管这么多

2. 混在中后排人群中，这么多人、这么多课、这么多事，只要没有明显特征，老师确实很难记住某个人
	* 所以要么拉近距离，要么隐藏到底( 我选后者
	* 上学期毛概，老师比较严，代课没坐座位号、去坐后排了，老师判我没来，我让代课去找老师，然后从缺勤 → 迟到。代课虽然跟老师接触过，但根据之后的情况分析老师可能还是忘了"我"
	* 然而如果经常在老师注意范围内，就比较危险了。还是毛概，最后1次课考试(就坐原来上课的座位号)，他发现近处某个同学不一样(我也不知道这是怎么看出来的)，就直接赶出去了(不过代考是另一回事了)

3. 理论课，但凡点1次名，很可能就有下1次了，早点找代课吧，赌ta不点名可能会额外生事

4. 分组之类的也是常态了，这种其实不慌，各种分组操作太麻烦，老师一般只会根据花名册顺序分组 OR 自由组队
	* **完成作业才是要点**
	* 自由组队线上就可以解决，老师让小组坐一起，其实也不慌，因为任务才是重点

# (三)4.1.星期3
## 1、狼的代谢方式🍚
日常走神💭

1. 狼只吃肉吧🤔

2. 肉 => 肥肉、瘦肉

3. 肥肉基本全是脂肪，瘦肉大部分蛋白质，一部分脂肪，很小部分碳水

4. 那么热量来源大部分是蛋白质，另一部分是脂肪( 看它吃的肥瘦肉比例吧😄

5. 人类`低强度运动 => 主要脂肪供能`，`中高强度运动 => 主要碳水供能`( 不过都是`三大营养素混合供能` )

6. 那么狼的供能方式不可以用人类的描述( 应该是废话

7. 但狼要怎么做到蛋白质、脂肪供能，还可以长时间剧烈运动，达到人类碳水的效果🧐

8. 猜测狼的蛋白质代谢能力( 好像蛋白质 → 碳水，叫`糖异生`? )、脂肪代谢能力极强，后者需要持续充足的氧气供应，于是推测狼的呼吸系统非常强

9. 同时因为蛋白质代谢快，更容易进行`细胞自噬`，清理老旧破损细胞，于是狼的恢复、成长也很快

10. 疑点🔍

* 狼真的不会吃碳水?

* 有没有可能主要还是代谢脂肪，毕竟从人类的角度看蛋白质太难分解供能

* 食肉动物也不是天天吃肉，应该大部分时间都在逛、躺，真正捕食的时间比较短，只在这一段时间爆发，然后用肥肉( 脂肪 )垫着肚子等下一顿。所以第 `7.` 点应该也不是`长时间剧烈运动``

* 有没有可能有其他的能量来源，比如人类好像最优先酒精供能，另外有机物这么多，你说它用醋酸、甲烷、石油/原油供能，我也(可能)信🤣
