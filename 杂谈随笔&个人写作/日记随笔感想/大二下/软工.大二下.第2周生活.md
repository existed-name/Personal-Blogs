# (三)3.14.星期6
## 1、这篇博客的起因
这几天学习进度还比较快，不过就很想看书获得更多快感——还没到半个月，就要看完3本了，估计这个月可以看五六本了(图书馆借的小说，爽[doge])。按照我前几个月的想法: 顺其自然，想干什么就干什么，想学就学，想看书了就看个够。不过发现自己跟上瘾一样一直看(就算不是网文，但毕竟也还是小说😅)，有点担心，但心里也懒得去管。直到今早上，洗脸的时候突然想到，应该是这个星期没写博客的原因

——我的生活结构就是推学习进度 + 看书 + 写博客 + 跟AI聊天 + 锻炼，写博客给我一个知识整理、输出的机会，然后给我一点成就感，而且我潜意识也希望自己高产。然而因为这个星期没怎么写博客——或者说，只是日常随便写作，于是**生活少了一环，自然就不平衡了，需要从其他地方多补充点东西**，于是就想多看书了🤔

发现这个原因后，虽然暂时还没动笔，但内心清醒了点，也就对看书没那么上瘾了，或者说恢复`正常`了

随后，就开启了自己的**日常感受总结**( 继续水博客😄)

# (二)3.12.星期4
## 1、勇敢一点
前几天看公寓的羽球场有人打球，想去参一个，但不好意思、害羞、感觉别人单打自己加进去不太好，好在室友鼓励了1顿，过了一会儿下去碰碰运气，可惜发现下雨了；今天旁观半小时，终于是鼓起勇气问人家，对方也是爽快地同意了，不过因为紧张(跟不认识的同学打)、有几天没打了，状态没那么好

但起码还是跨过了心理障碍，以后也可以厚着脸皮找其他不认识的同学打了(这可能是野球场成长的必要过程吧~~~)，不过我还是不理解为什么会害怕

从高三才开始打羽毛球——把羽毛球抛得很高来发球[doge]——先跟好朋友打，之后因为热情、想提高技术，特别想跟高手打，总是不放过跟陌生人打球的机会，也把半熟的朋友拉去打球，拉近感情，到大一虽然中断了1学期，但还是愿意和不太熟的同学打球

直到现在，我突然发现自己竟然害怕和不熟的人打球——可能是太激动，可能是太久待在熟悉的环境，也可能是自己练了这么多次、害怕打不过从而有心理上的否定(尤其是不熟的人)

然而，等到跟他们打完，我才发现**即使不认识，但是打球的时候依然很爽，依然不需要害怕——就好像只是体验了不一样的生活，然后学会了拥抱各种生活**

# (四)3.15.星期7
## 1、去争取想要的
就比如，想在今天下午打球，于是在上午就借了宿管阿姨的扫把扫掉球场的积水，让它快点变干，然后把健身从下午移到上午，甚至干完饭又扫了下积水，等到下午，我在犹豫要不要去拉人打球，发现球场被占了，于是果断地加入对方(也是胆子变大了)。这样，既完成了规律训练，又打到了球( 长期都是下午健身，看来还是要敢打破固定生活结构/节律，起码得灵活一点 )
