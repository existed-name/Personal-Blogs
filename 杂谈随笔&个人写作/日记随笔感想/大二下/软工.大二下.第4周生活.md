# 3.25.星期3
## 1、饭后活动🚶
以前饭后、坐一段时间都会站半个小时以上，因为心里觉得没那么容易肚子堆积脂肪，之后用腿的频率逐渐变高(跑步、羽毛球)，每天站这么久腿胀，于是就比较少站了。问AI，说饭后站/蹲/提脚后跟(踮脚)比坐的血糖更低，如果走的话就更降血糖了——于是我想，等以后，肯定每顿饭后走一会儿，降降血糖、延缓下脂肪堆积

今天我突然想到，我既然可以边看书边走路(就在宿舍转)，那也可以**饭后，走一会儿 + 同时看书**。不需要走太久，几~10min就够了，这样不废腿、也可以降血糖/没那么容易囤脂肪

之后我又担心，每顿饭后就看会儿书——因为是情节性小说——会不会容易过度吸引自己，导致回寝室坐下后静不下心写代码。不过事实证明不需要担心: 如果那一段时间刚好我很想看书，就顺其自然；如果那一段时间我想写代码，但是被拉去走路 + 看书，会有一点抵触的心理(不能完全把心放在看书上面)；而且高频、短时间、有一点强迫性地看小说，应该可以像慢慢排水一样、小步释放看小说的欲望，一定程度上减缓下一次想看个够的心理

当然，我感觉边走边看书，跟边走边看手机等等，都是一样的，只不过因为只在宿舍里面转，比较安全。而且也不一定非要站、走，只要**不马上坐、活动一会儿**就行

之后发现，可以顺便刷校园跑，走快一点就行( 把1天的量分给几顿饭后来刷，轻松一点😂 )


## 2、被动帮忙
我一个要好、但不喜欢找别人帮忙的同学来寝室借热水泡面——还差一点水，但是他们寝室刚好没水了

我一看饮水机，忘打开加热了，于是让他等一下、我一会儿来叫他(很近，面对面的寝室)，不过他不想麻烦我，就撤退了。我想到保温杯还有热水，去串门，但是不用了。等几分钟水烧好，再去串门，还是不用了

转念一想，人情不是什么时候都卖得出去的😂(帮对面寝室个忙，也好找对面要签到码鸭🤣)也就只有**别人主动找我的时候，是我给帮助的(相对)最好时机，如果是我主动去帮助别人，倒像是主动黏上去、让人有戒备**

如果亲戚家也有读高中的孩子，ta们可能会让我多跟ta们的孩子交流方法、教一教啊之类的，但是我想的话，为什么不是我的弟弟妹妹们主动来找我，而是我去找他们🤔(当然，双方都不好意思)所以以前就想了这点: `正常情况下，别人找我，我才帮忙`

不请自来帮忙的情况，可能就是`熟人亲人 + 隔阂小`、`谈合作(利益交换)`、`骗子`吧



# 3.26.星期4
## 1、会燃起来的🔥
以前健身的时候(学校的单杠双杠，不是健身房)，那个勤快啊，隔1天练1次，1星期3练，对当时的我来说强度也算中上(都是力竭 / 手没感觉到胀了才回去)，但是那时候竟然还充满热情，总想多练、多变强。之后加大点强度，间隔时间也拉长了，2天、3天，甚至4天(当然，中间会小小练一点)，但还是有不少热情。不过差不多寒假的时候，没那么多热情了(而且同学拉我去打羽球，肯定也比训练好玩儿😂)，但毕竟完全当成了生活的一部分，就跟吃饭一样正常，练的时候好好练就行。等过了寒假，偷懒的心理更强了，可以间隔5天练1次，甚至现在间隔7天😂(不过每次训练的容量也加大了，然后间隔时间里面练练小臂)，完全没那么想练了——当然，习惯的力量挺强的，但也没有太多激情了

可能是燃尽了😄

然而，洗澡走神的时候，想，有点想吃食堂某某套餐了，要不训练完奖励自己一顿。突然好像窜出一阵训练的欲望，虽然是奖励的附庸，但它确实持续了一会儿，直到我仔细感受，膀子还挺累的……

可能是**热血逐渐冷却，变得温和**，只是做着“必要”的事情，在做的过程中确实用心、血热了一点，做完后再热一点(高兴、成就)，但不久也恢复平静，**比以前更难加热沸腾了**——就算只有瞬间

不过我觉得更可能是频繁打球、跑步走路等等消耗了大部分热血(腿真的燃尽了)，于是训练的积极性下降了，而且训练后并没有给自己实质性的奖励(搓一顿爽的😋)，也只是靠内啡肽“为爱发电”

另外，问AI，**一腔热血的兴奋跟一大堆激素相关**(儿茶酚胺/多巴胺/睾酮/皮质醇)，可能是我这些激素不够(饮食、外界刺激)，以及兴奋阈值提高了

总之，虽然暂时起不了大火，但就这样温和地烧，不知道什么时候，会爆火的——正如在<u>[上学期总结](https://zhuanlan.zhihu.com/p/2013893281885463863)</u>里想到的**时候未到**


## 2、 为情怀买单🧾
听说洛克王国手机App上线了，看1个室友玩了一会儿，再想起另外2个同学偶尔也会去4399玩玩网页版、自己小时候看隔壁大哥哥的圣光迪莫感觉我靠好厉害，不禁感叹情怀的力量确实不小，**给ta小时候注入点东西，就成了童年的一部分，而大部分人是怀旧的，对童年完全好感**——甚至去除了不少难受的时候，就像高中压榨人们，但人们总会怀念高中时光——于是自然愿意为情怀买单，算是很聪明的**投资**

不过我想，每代人有每代人的情怀，B代可能看不上A代的xxxx，但A代却视之珍宝，但我想同一种事物，只要活得够久 + 个性化包装，可不可以变成几代人的情怀

对了，看游戏界面，感觉有点像某原神😂



# 3.28.星期6
## 1、跨不过去的墙🧱
日常走神，想起小学的时候，到楼顶上玩儿，看到不远处有跟我差不多高的墙，脑子抽搐1下，于是我直冲而去，想要翻过去，我跳起来、双手扒在墙上，把自己往上撑，不过没撑住，降落了。但我还记得当时看到的逆天一幕: 这墙外面全是空气😅20多层高，我但凡翻过去，这辈子就有了……

我不得不感叹自己运气之好，或许也得感谢自己的不够强大——在尽力去做，去冲击的时候，失败了，没有突破那面墙。可能感觉遗憾、受挫，但会不会我没有看到成功突破后的巨大风险，一心想着要跨过这面墙——然而终究还是实力因素: 实力弱，跨不过去，但没有从墙上掉下去的危险，实力一般，跨过去，没把握住、掉下去，实力强，跨上去，还不会掉下来

但总的来说，**跨不过去的墙，也许是自己的保护墙，保护这个阶段的自己**——以前的自己看不到墙外掉下去人就没了，现在长高了自然看得到了。不过我还是在想，会不会有人明知道很危险，还是奋不顾身跳过去
