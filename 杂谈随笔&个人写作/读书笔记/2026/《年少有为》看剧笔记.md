## (一)剧情介绍
1. 改编自小说《亏成首富从游戏开始》
2. 听说小说里面是系统，对应剧里面的惊鸿集团老总司马先生(`司马明`，以下简称`司马`)
3. 剧情
> 主角被公司开除后，司马资助他创业。亏多少他就可以赚多少、但公司盈利就只能拿5k的工资  
> 然而他的一系列赔钱计划都失败了，公司越做越大，他的5k工资也非常稳定  
> 即使中途红温退出，但经历毒打后还是回来了，甚至佛系了
> 直到得知自己只是资本的小白鼠，他在崩溃之下关停业务赶走员工  
> 但良心折磨 + 回忆杀，他请回所有员工，并和司马谈判拿下独立运营权，最终以建成腾达大厦结尾……



## (二)情节分析
**1、主角被选中的原因**  
我觉得可能是
* 《富晖饭碗保卫手册》指出富晖集团的内部问题、员工应对方法，有希望成立一个避免成为惊鸿集团的公司
* 普通人，不像其他人追着求资助
* 良心: 自己都吃不饱了，还收养了1只猫
* 脑回路清奇😂  
  👆主角是被司马监视过一段时间的


**2、司马和助理下跳棋，讲了一堆哲学**  
(1)`你千万别小看了这跳棋，你以为它简单，可往往越简单的游戏，流传的时间就越久`  
好像是这样的，但我觉得不简单😂  

(2)`你看，只要有棋子在，我就可以借助我的棋子或者你的棋子，越过它往前跳一步，每个棋子都一样，没有高低之分`   

这里暴露了主角其实是司马的棋子(用来抵达某个目标)，也照应了司马万说`你跟我们几个儿子是一样的，谁能最终冲线，谁就是那匹好马`

(3)`不着急，你看，当你搭的桥足够多的时候，你迟早可以抵达目标，甚至你想停都停不下来，更甚至到最后，不是你在下棋，而是棋在下你了`  
照应了后面主角掀翻棋盘、自己下棋

(4)`成立惊鸿的时候，我们这一群人，以为可以一直走下去，但越往后越发现，其实什么都控制不了，和资本打交道这么多年，我只明白了一件事：只要上了棋桌开了局，就不能停，必须继续下下去`

人在局中、身不由己、被大势裹挟前进，司马背后的一串照片，从很多人逐渐变少，最后只剩下自己1个人。有弹幕说：`真正的赢家，不是赌桌上的赢家，而是开赌场的人`


**3、主角黑化**  
司马的大儿子司马万告诉主角真相: 像他这样的人很多——司马和主角见面的飞机上有一大把同样的保密协议，主角也只是小白鼠之一，但是主角的公司成功了，于是可以作为惊鸿的下一任，继续由司马掌控。而司马万不想当自己爸爸的棋子，想要推翻棋盘，于是就告诉主角真相再加以利诱。而主角虽然习惯了1个月5k + 代驾，但不能接受自己原来是一个棋子、一个实验品，所以黑化、关停公司

当然，主角也拒绝跟司马万合作了: `因为我和你，和你们这群人，从来，永远，都不是一类人`


**4、主角请员工回来时，大家不理他**  
主角没有告诉众人真相，只是说“自己在玩儿他们”，一方面是否定了众人的心血——像他们这种员工缺的不是物质，而是尊重欣赏理解，一方面众人感觉自己被当作棋子——跟主角一样——谁也不好受，然后因为爱的太深、伤得也深，于是众人都回避主角(虽然被弹幕喷不懂得感恩，但是我觉得也可以理解)

但是有一说一，这些员工真的就只看表面、没去想一下深层的原因？主角代驾的时候虽然说自己体验生活(顺便赚点钱😅)，然后大家就信了；主角给员工做代驾的时候，员工听到了催还贷的电话，主角说这个是骚扰电话，还真就信了?(当然你说员工以为主角为公司贷款也是可能的)；最后主角关停公司的时候，这群人还真就信了是主角`玩儿`他们——前面出现3个司马的儿子了，都应该感受到事情不对了，然后自圆其说是主角的家族内战(好一个重组家庭🤣)，不过主角的兄弟马洋一直以为主角是富二代，再加上最近的司马，以及自己不太聪明的样子，再添油加醋八卦一波(剧里面有这个情节)，然后大家在安逸的环境待久了、非常单纯，就信了，也说得通😂(不过年轻人确实更喜欢直说实话、大家也互相信任🤔)


**5、没人关心主角**
1. **没人知道真相**，主角必须保密(虽然独自承受窘困落魄、看着身边人发达的痛苦)、都没有一个人可以倒苦水(司马派过来的助理也不会当他的心理医生)

2. **被神化了**，每次都成功、不按常理出牌，大家捉摸不透，都以为一切都在主角掌控之中，自己不用管(就比如班上某个同学长期考第一，大家也就习惯了，没人会在意)

3. **身份不一样**，员工一般都不会从老板的角度思考——从**现实**的角度看，做好自己的、让自己舒服就够了


**6、剧终再见司马**  
(1)15集就已经出现过司马的1个住址: 老区一栋破旧高楼的顶楼(当然装修非常高档)
虽然他说过`我，从小是在这长大的，无论再有钱，我也不会忘了自己是谁，更不会离开自己的根，只有和老百姓住在一起，我才会知道这个世界上每天都在发生什么`  
不过弹幕:
> * 说是在闹市里面更贴近生活但其实端坐高阁，完全不在乎
> * 意思是住在穷巷子，但其实他还是不懂老百姓

所以这是虚伪的资本家行为?

(2)关水龙头  
主角来的时候发现司马的楼上有很多水洒下来，上来后发现是草坪里的浇水系统往周围喷水，趴在栏杆往下看，水洒到了行人身上，于是主角把水龙头关了，行人也不会被楼上的水淋湿

弹幕:
> * 司马从来没有低头看过
> * 水龙头是惊鸿，花草是腾达，路人是员工(的尊严)

这里确实是最难理解的地方

(3)顶楼原本高档，主角再来的时候已经破败: 各种雕塑名画装饰都没了，水池没有金鱼只剩垃圾，一幅破败的样子。可以肯定是惊鸿衰败，还可能表示司马已经到了绝境


**7、腾达股份(所有权) = 主角51% + 员工49%**  
主角跟司马谈判后拿到了腾达的独立运营权，但是剧里面没有直说司马怎么同意“由主角来掌控棋盘”，猜想
1. 要想独立，首先一定是协议作废，惊鸿不再投资和约束

2. 主角的**威胁** + 惊鸿的衰败: 他说`腾达必须独立运营，这样腾达永远都不会变质，更不会变成你的惊鸿`，司马万告诉过他`腾达走的这条路，让我父亲看到了希望，惊鸿在他心中早就已经腐朽衰败，而腾达，是他新生的机会`，也就是**这么多实验，只有腾达是司马的希望**，想要保留希望，就必须听主角的，否则后果自负。而且主角也说过`司马先生，腾达最大的资本，不是您的财富，而是这些人，而我，不想变成你这样的人`(不过不知道是他自言自语还是真的跟司马对话)，也就是只要团队在，他就可以单飞、东山再起，完全跟司马脱离关系。而且司马已经底气不足: 他开的条件一再宽容并且跟主角协商，语气委婉，而且眼神不安看着主角不敢喝茶

3. 其他可能原因
* 主角表面上51%股份，实际上要把钱交给司马(也就是代持股份)，但所有权还是在主角手上
* 或者主角答应帮衬一下惊鸿集团，但是惊鸿交给了司马的几个败家儿子管理、而且司马早就对惊鸿失望了，就算帮助、也只是延缓衰败
* 弹幕说`老头看到了以前的自己其实也可以这样选择吧`、`老头看到自己年轻的样子`，剧里面司马的眼神黯淡伤感，可能是接受了棋子翻盘的现实(以及主角的嘴遁)，突然良心发现直接把腾达送给主角(虽然老资本家几乎不可能)


**8、为什么成功**  
**(1)先来看看主角打下的江山**
1. **腾达游戏**: 前几个游戏太逆天了，触及玩家的逆反心理 + "再试一次"，而之后真的用心(初心+细心)做游戏，也爆了——不过主角本来可以不帮《神之山海》的，但是良心过不去

2. **摸鱼网咖**: 网咖旁边有个小哥觉得里面的歌手太垃圾，就自己上，结果爆了——这个现实是不可能的，就算有隐藏大佬也可能会一直潜水不冒泡，而且也可以直接告网咖扰民

3. **树懒健身**: 从健身 → 养生，下班的人没力气健身，就来静养身心(瑜伽、躺平、吃喝玩乐……)——这个思路好，受众确实广

4. **无名私厨/明云山庄**: 某明星来这里摆拍过，之后一群粉丝找上来，就爆了——不了解娱乐圈是不是这样的

5. **终点网文**: `如果每日更新超过一千字，次日将会被严厉禁止码字……如果更新在五百字以内，那我们会认为你们有在认真打磨作品……我们要摒弃所有的爽点、苏点、金手指，推崇败者为王，把甜宠写成苦宠，把爽文写成憋文`、**让好书止步于此**……然后主角的前台、产品经理写的文都爆了——当时弹幕提醒很多比较惨的文学作品(余华)就符合他们的要求，不过感觉剧里面的不怎么样

6. **圆梦创投**: 自动贩卖机融合电话亭，可以躲雨、发泄情绪、吃喝用住齐全(离谱)，成为良好的私人空间，还可以带动周边——这个想法我觉得可以(有钱的前提下)，因为确实稀奇好玩儿，除了20r/10min有点贵(但应该是自助餐了😋)

7. **飞黄影视**: 本来以为它持续烧钱且没有成效(`黄思博`的那部剧就没有停过改剧本，等到最后才杀青)，然后21集开头才发现这玩意儿真的起飞了——不过好像影视业挺痛苦的

8. **四壁公寓**: **最高环保标准**(0甲醛) + 家具家电顶配&智控系统&定期更新 + 24h保洁 + 只租不卖&禁止合租短租&十年起租&一次性付清；当然，宣传的人来自终点网文，当时被主角安排的管培生劝退改做自媒体了，也算是运气 + 连锁反应——不过现实世界，一次性付清10年租金对租客的风险很高，于是就挑选出了不缺钱的人，再加上配置确实离谱，如果再加上宣传对比(主角那片地确实偏得很)，我觉得能爆也比较合理

9. **迟行工作室**: 收购天火后成立的工作室，之后业务挺好的

10. **逆风外卖**、**马尾直播**……

**(3)员工是一群死士**  
虽然员工都是别人不要的，但不代表员工没能力，只是缺少合适的平台

他把福利待遇拉满、全部都放给员工去做、一稿过，员工主动性积极性拉满、自发组织起来肝项目、都知道自己该干什么

而且他没有多的管理层，组织机构非常扁平，动物的层次好像是细胞 → 组织 → 器官 → 系统 → 个体，我感觉他的公司是细胞(员工) → 组织(员工自发组织) → 直接组成个体，效率是真的高(要传话只需大吼一声大家都听得到)

**(4)贵人**
* 司马: 可以算半个吧，虽然他的目的是控制，但还是成就了主角

* 林晚她爸: 神骅集团老总，当时李石带人来砸主角开的网咖，主角是想亏钱的、但突然于心不忍，然后这位老总来救了波场，也算一点吧

* 李石: 这玩意儿是真的贵人，有事是真上，利用资源(他爸是富晖集团老总)多次赞助腾达。主角关停公司把公司账户的钱全散给了员工，后来为了启动公司要卖房(攒了20多集啊)，也是李石出高价接手的。虽然脑回路可能比主角更清奇，但还是折服在主角的反套路之下🤣当时腾达在竞争，他爸让他别帮腾达，不过他的格局还是挺大的: `可是爸，我觉得咱们现在不应该想的是如何霸占整个蛋糕，咋们想的应该是如何让整个蛋糕变得更大。如果一个行业只有您一位玩家，那这个行业才是真正的完蛋了`

**(5)逆向思维、“看到”潜在需求、运气、联动**……

## (三)细节
**(1)富晖集团的拼音缩写**  
简称`FH`，`F → Family`，`H → Happiness`，然而主角在这里被开除时没有补偿金、同事也漠不关心；之后富晖集团的子公司天火则更不当人(经典压榨员工)；甚至天火被曝出来后，富晖集团的声明不痛不痒。确实讽刺

**(2)司马发给主角1个G的约束文件**  
1GB = 1024 * 1024 * 1024字节，UTF-8编码下1个中文字符3字节，那么全算成汉字就有`357,913,941`字(3亿多字 = 1k字高考作文 * 30多万份)，所以文件覆盖的约束非常广，基本钻不了空子

**(2)时间细节**  
当时主角给员工安排的4090显卡，我查一下发现4090显卡是2022年的，确实对上了剧里面设定的2022年；而且简历里面的工作经历都对得上时间

**(3)** 问`一个能把自己简历包装得这么好的选手，却每份工作都做不长，你知道是什么原因导致的吗`，答`年轻人没定力呗`，这确实反应年轻人的追求跟现实的矛盾，只能人适应社会，哪有社会适应人

**(4)** 过年群里面一堆发红包的，但是主角不敢领，可能是领了就得再发出去，而自己也没钱了😅

**(5)** 石火、路知遥，都是1个人带7个人，台词也是`一带七`，不知道是不是 → `一打七` → 鼬

**(6)** 杀青后，路知遥说这是第1次跟石火合作，然后石火给他1张照片: 以前的一部剧里，龙套石火给主角路知遥牵马 => 小人物也可以变成大人物

**(7)** 主角跟司马谈判完后，说自己放个长假。包旭说`你这个假放的也太长了吧……原来自己喜欢旅游对吧`，所以推测这段时间可能去旅游了；也有弹幕表示可能是去帮惊鸿了

**(8)空的董事长室**  
主角之前就很少在办公室——跑代驾去了没时间回来，现在独立、建立腾达大厦后，他的办公室还是空的，我觉得是表现主角没有忘记自己只是个普通人、并没有被资本洗脑

**(9)** 主角跟司马谈判完后，辛助理才过来，不知道司马跟没跟她讲什么(毕竟她是司马派过来的助理，也是主角、司马之间的桥梁)。不过现在辛助理还在主角的员工团队里面，1种可能是她继续监视主角、但不干预只上报情况，1种是她真正成为腾达的一员(而且主角的团队也确实需要她)，当然我觉得她自己也喜欢腾达

**(10)保留梦开始的地方**  
虽然有了腾达大厦，但是主角还是把公司的原址留着，并摆上了刚成立的照片(主角、马洋、辛海璐、包旭以及一条黄带)——`腾而不忘初心，达则兼济天下`



## (四)感想

* 腾达给钱让游戏主播黑自己
* 天火每年几千万投在营销、控评/舆论上面

* 真正背弃主流价值观的勇气智慧: 拒绝房车贷款彩礼，享受单飞生活?(好像也可以😄)
