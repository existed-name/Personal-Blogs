## 4、接口测试
都“跑起来”了，那就先用 ApiFox 测试一波吧

* 来到业务模块的 `Controller`，找几个路径过来

* 先从登录路径那里，把`username`、`password`参数放进去，从返回的JSON数据拿到token

* 再去新的路径，把token放进`Headers`，然后访问接口

* 又炸了😵

```java
org.apache.ibatis.binding.BindingException: Invalid bound statement (not found)
```

* 去看看`Mapper`接口，这里的包叫`dao`而不是`mapper`，然后接口叫做`XxxDao`，不过都是那个意思，不影响

* 然而，我靠还有重载方法，把名字改了，重跑，炸

* 给那个改了名字的方法添加XML映射——等等，这个XML怎么这么离谱

```xml
    <select id="selectListView"
		resultType="com.entity.view.CartView" >

		SELECT  cart.* FROM cart  cart 	        
        <where> 1=1 ${ew.sqlSegment}</where>

    </select>
```

* AI说是MyBatis-Plus，好吧……

* 先复制粘贴再说，虽然还是炸了……

* 中场休息( 脑子需要换一下了🧠人都麻了 )，已经16点多了，收拾东西 + 干饭 + 打球(🤣) + 洗澡 + 收拾东西，20点多回到岗位

*    试了几个`Controller`的路径，都是`org.apache.ibatis.binding.BindingException: Invalid bound statement (not found)`

*    AI说是项目没有加载到这些Mapper接口、XML，后来转了几下发现都没有`@Mapper`，就在启动类上面加了`@MapperScan( "Mapper接口的包路径" )`，重启后还是这样

*    之后再问AI说MyBatis-Plus要在`application.yaml`里面加XML的路径，于是就去`springcloud-module-system`的`bootstrap.yml`里面加了

```yaml

  mapper-locations: classpath*:mapper/**/*.xml  # 扫描所有模块下的xml
  configuration:
    # 开启驼峰转换（数据库字段 user_id -> 实体类 userId），虽然也没有必要，因为都是小写 + 拼音😵
    map-underscore-to-camel-case: true
```

## 3、修改远程配置

原来是后端还没启动😅

启动……

我靠，今上午还没事，今下午就报错了

```java
java.sql.SQLNonTransientConnectionException: Public Key Retrieval is not allowed

Caused by: com.mysql.cj.exceptions.UnableToConnectException: Public Key Retrieval is not allowed
```

跟着AI操作，修改业务模块的`bootstrap,yml`的数据库URL

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/数据库名?useUnicode=true&characterEncoding=utf-8&useSSL=false&allowPublicKeyRetrieval=true
    # allowPublicKeyRetrieval=true: 允许nacos从服务器获取加密工具(公钥)，用来加密数据库密码
    # useSSL=false: 关闭nacos、MySQL之间的private隧道

    username: root
    password: 密码
```

nacos模块的配置也是对的，不过运行后还是同样的报错

AI提示可能是Nacos配置中心把本地配置覆盖了，果然是远程配置有问题: URL、数据库密码都需要改(不过挺离谱的，它应该读取数据库`config_info`的配置，那么今早上就应该报错，但是没有，那可能是今早上用的本地配置😵……或者根据AI说的，可能是今早上用的之前的缓存/快照，今下午更新快照……)

## 2、阶段性总结📕
* 跑通基础的`SpringCloud-Alibaba`项目

**①基础结构**: 

* db放sql文件作为数据源导入本地数据库(来到sql文件，全选然后运行sql)
* common放一些pojo、utils
* gateway作为网关
* module-system业务模块
* nacos模块是远程配置

**②启动顺序**: 底层组件 → nacos模块 → 网关 → 业务模块

* 看下各个模块有没有自己的启动类
* nacos需要下载安装`nacos-server`(当然遇到了问AI就行)
* 这里还好还没有Redis、Docker之类的，还没学过来😵

**③项目配置优先级**: nacos远程配置 > 本地`bootstrap.yml` > 本地`application.yml/properties`

* 确保远程配置、本地配置的数据库密码、URL都是对的(或者添加数据源的时候就设置成项目配置里面的密码)
* 远程配置可以看数据库的`config_info`、历史记录看`his_config_info`

**④**跑通后端，用测试工具(ApiFox/Postman之类的)**测试后端接口**

* 报错出现`org.apache.ibatis`，就跟MyBatis相关(ibatis是上一代吧)，看看Mapper接口
* `org.apache.ibatis.binding.BindingException: Invalid bound statement (not found)`，是没有扫描到Mapper、XML，看看Mapper接口有没有`@Mapper`、启动类有没有`@MapperScan( "包路径" )`
* 如果是MyBatis-Plus，需要在配置文件(`bootstrap.yml`)里面添加XML路径

```yaml
mybatis-plus:
  # 扫描配置文件同一目录的mapper文件夹的所有xml
  mapper-locations: classpath*:mapper/**/*.xml  
```

**⑤**Node切换版本、兼容老依赖

* 安装配置NVM
* Node >= 16可以直接命令行下载，否则去镜像站手动下载Node、NPM塞到NVM里面
