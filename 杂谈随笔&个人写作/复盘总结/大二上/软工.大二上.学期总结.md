# 软工.大二上.学期总结

---

# (一)引言🧩
一个学期又飞快的过去了，学期初挺有激情的，中间又是断断续续的失落、平静、乐观，种种情绪杂糅，又回到了现在新学期的激情。按照习惯——也可以叫做“我的习俗”，总结自己的一学期



# (二)我的变化📃
虽然说时间很快，但是心里觉得，其实变化并不大——好像都是自然而然的、然后一晃就过了一学期，但也还是很有成就感，以及给自己的焦虑不少安全感


## 1、看书变成生活的一部分📕
高中看的是教材，这个不用说；刚上大学就看的知乎，反正刷到啥就看啥吧——然后自诩不刷视频不打游戏、满满的优越感😂后来我感觉到是我**对文字有一种渴望**，就是想看这些文字、把他们串在一起、填满我的脑子，于是开始少少的看书。之后发现自己就是有一种想阅读的感受，反正知乎是看、书也是看，于是大一暑假就试一下不想学的时候就看书、代替刷知乎刷公众号，感觉挺有效果的，无非是自己心理不太习惯

暑假后来到大二上，这时已经比较依赖从书里面获取文字，于是人生中**第1次自愿从图书馆借书**。起初只是1本1本地借——1个月看1本，应该也够了吧🤔之后发现越看越起劲，然后想，反正不可能一直推学习进度，早就没那个精力了，效率不高、心理抵触的时候，直接看书算了

11月的时候硬是看了5本书(<u>[2025.11月.读书笔记](https://zhuanlan.zhihu.com/p/1991814251413787213)</u>)，自己都震惊了，当然《银河帝国》是真的可以上瘾😂

之后，书在我的生活中的地位也就稳稳当当了，一个月借他4本书，摆在寝室书架上，想看就看，然后继续学……

看书夺走了我对刷知乎、公众号的爱[doge], 然后贡献了我1个<u>[读书笔记专栏](https://www.zhihu.com/column/c_1991579880740110802)</u>


## 2、健身，不再是弱狗💪
大一下4月份开始高频、低强度的自重训练，用学校的单杠练引体向上、草坪练俯卧撑/深蹲等等(也就是街头健身，没钱、也不想去健身房)，逐步优化训练计划、饮食，现在过了11个月，从169cm50kg → 170cm56kg，虽然体重还是轻，但是看到肩膀大臂小臂胸肌明显变厚，果然，健身是给自己看的🤣(不过可能因为基数小、饮食控制得多，涨得很慢)

有一说一，最开始是大一上节食保持低体脂，但是后来查资料，还是得提高代谢，于是就增肌了。不过增肌的过程中，虽然体脂率逐渐↑，但是完全没有以前那么在意腹肌的清晰度了，增肌本身就给了我很大的满足感了——而且学校的单杠双杠走几步路就可以用，也不麻烦

不止力量训练，再保持晨跑/走路、羽毛球，而且寒假跟同学练启动步又把小腿肌肉练大了些，体能也是大大提高，现在5公里平均配速可以保持4'50''~4'30''——以前哪有这个状态😅

再加上每天早上站桩，身体素质提上去了，这学期末完全没有以前那么怕冷了，某次晨跑完没及时穿衣服感冒，症状都很轻、很快就好了


## 3、AI又会了一点🤖
**(1)实战经验💧**  
高中毕业的时候，看博主推荐就入坑了AI，那个时候(2024)国内AI还没那么好用，但是因为我的认知还不够，就只是用来写作业、问简单代码、问规划。不过因为自己脑子的特殊构造——总是把问题想得很复杂😂，恰好就把提示词写得很清楚(那个时候还不知道`提示词`是什么)

之后逐渐熟悉基本操作，开始用AI帮做PPT、突击考试、做Qt作业、更复杂的问题，提示词也更像样了(`角色-背景-需求-约束`)。大二上也是各种作业(PPT、报告、代码、实验操作等等)，继续“磨练”技巧，积攒经验(以及稳定心态，因为豆包时不时用着很冒火😅)然后想出多对话(1个对话作为主脑🧠，1个作为审核🔍，1个作为劳动力/开发💻)、让AI帮我写提示词……

**(2)更新🔼**  
大二上后期，终于正式入坑国外AI，以及必要的提高自己的网络技术，把自己的工具流更新了一波，国内AI退休为辅助工具
* Gemini/GPT: 通用(问代码问题、规划项目/论文报告……)
* Claude: 写项目、写论文报告
* Grok: 搜索引擎、简单问题
* Kimi: PPT
* 手机还是用的豆包/DeepSeek

然后解决了一些AI问题，建了自己的<u>[AI博客专栏](https://www.zhihu.com/column/c_2004485413633552936)</u>，虽然说数量还比较少，而且被系统制裁过

**(3)写代码⌨️**  
之后用AI针对学校教务系统做了1个填问卷调查的脚本，算是**第1次正式的AI编程**(<u>[仓库]()</u>，虽然还有些bug没修，而且只适用于自己学校)，收获是: 

1. 小程序的AI开发流程🤔

```java
①先理清楚目的、开发环境、大致功能&运行过程，整理成提示词让对话1给出项目背景说明、拆分模块、相关测试操作
* 听说各种AI编译器可以直接Planning

②把项目背景说明拿给对话2，再把模块1的内容交给他，让他生成详细的提示词
* 对话1、2如果不是同一个AI，思路会差得比较远
* 感觉Gemini要精简实用一点

③对话3，先发项目背景说明，然后模块1提示词
* Claude比较舒服
* 特别是让他`开启Artifacts功能，把代码、说明、教程写进 Artifacts(区分多个文件)，对话里面仅保留简短的文件说明`，这样就非常清爽

④改bug，跑通模块1

⑤重复，逐渐把代码堆起来、串起来
* 如果负责开发的对话3比较长了，可以把下一模块的内容发给他、让他总结下一模块需要的内容，然后转移到新的对话

⑥最后让AI重构一下(因为比较小，甚至所有文件都可以直接发过去)

**不过目前还只局限在网页端，还不会调API/AI编译器**
```

2. Maven项目打成`FatJar` + 剪裁Java环境 + logo(需要转成`.ico`文件)，拼成1个安装器/程序文件夹
* 打包的命令行命令可以做成`.bat`脚本
* 顺便产出博客: <u>[Maven 项目怎么打包](https://www.zhihu.com/question/580694901/answer/2004177783052592657)</u>

3. 仓库: 用emoji、徽章装饰说明，`merge`合并2个分支(版本)，打上`tag`然后`release`
* 已经感受到做个人项目的快乐了😄
* 不过还没学Git，就直接在网页端操作的😅
* 而且以前是直接当网盘来用的🤣

**(4)感想💭**  
我逐渐意识到，具体的细节我其实可以做，但因为我总是想得比较复杂，实际的效率反而不高，于是不如**把具体实现、模块规划交给AI，我负责高层构思、找出问题、引导AI，快速地解决需求**，这样我可以有更多自己的时间，也可以让更多想法比较快的落地💡就像人类利用机器人建造了《银河帝国》

然而AI的上限还是跑不了我的认知范围，熟悉了更多技术才好带他(或者他带我)做更高端的项目(还得继续学~~~)

**(5)emoji🤪**  
以前发消息就喜欢带表情，因为感觉更友好、没那么单调，之后AI都是当工具用(用提示词来命令它)，用GPT后发现这玩意儿怎么这么多emoji，就喜欢挑逗他，看他发emoji🤣后来为了让AI爆出比较多的emoji，我的提示词总会带一些emoji、语气轻松点(但是不会刻意要求他发emoji)。现在也就习惯了打字附带emoji😄……


## 4、顺其自然的写博客✍️
**(1)发展史📚**  
刚入学的时候开始写知乎(2024年9月)，当时想写、但没什么实力可以写，于是只能挑最简单的一些回答来写，后来回答一些C语言语法问题，羡慕那些大佬有这么高端的技术博客，或者有深度的思考，心想如果自己也有那种实力就好了

然后写了自己的第1篇总结，不过技术博客对我来说还是珍惜品。直到暑假，开始坚持写“技术博客”——总结自己学过的知识点。不过也是慢慢好起来了，博客也越来越多

当时我还在写日记、总结自己干了什么，于是有相当一部分知识点总结在日记里，没有整理成博客水出来——好亏啊啊啊啊😫

同时这个学期我也尝试了每个月总结，期末后一大把时间，我放弃了`private`日记，尝试`public`——总结这1天的学习成果、感想，写了几次后觉得不怎么样，干脆就拆成学习笔记、心得等等分开写(`高内聚低耦合`😄)，就舒服点了

总结发展过程: 写零散简单回答 → 记录型教程 + 知识点总结 → 取消日记，把学习笔记、感想全部写进博客，变成`博客驱动式学习` → 现在**学了哪个部分，就总结哪个部分发出来；解决了什么问题，就顺带发出来；有了什么想法，就记录下来……不刻意去写文章写回答，但坚持写作，顺其自然地写作**

# (三)感想🧐
## 1、曾经失落😊
<u>[觉得自己是个一事无成的废物怎么办?](https://www.zhihu.com/question/551444542/answer/2008316657479746147)</u>当时我也在emo，于是就搜到了这个话题、“想通”后写下这篇回答

因为看过更高的山，所以想爬得更高，然而能力和心气不对等，否定自己，然后失望。然后也就顺其自然了，心气放不下来，就是有这么高的目标、这么大的梦想；但回到现实，**我该干嘛干嘛，继续学习、看书、写博客、锻炼，拿到生活的正反馈，然后再梦一梦自己理想的样子**……


## 2、跳出生活🔬
置身事中，然后看不清事物的全貌。寒假后返校，我突然跳出了大二上后期、寒假的生活，开始回忆、反思这两个生活，我惊奇的发现，它们已经有不少地方满足我的比较理想的生活的要求: 
* 稳定的锻炼(物理上变强)
* 可控的饮食(干净增肌~~~)
* 肉眼可见、持续推进的(学习/项目)进度
* 比较高产的博客
* 边晒太阳边看书
* **自由、很少的约束、随心所欲**(讨厌上课作业实验考试等等学校任务😄)

于是我在想，**我已经有了很多好东西，只需要结合之前的生活、优化一波，那我就可以有更好的生活体验**。这不就好起来了吗


## 3、时候未到⏳
我还是太心急了，于是赶着赶着想要拿下一系列知识点，想要做出点项目。用AI做完脚本时，我才发现，**尽管去推自己的进度，不用焦虑自己的效率、还来不来得及，突破一定会来，只是时候未到**——也可以理解为`厚积薄发`——并不是积累就可以爆发，而是**积累后遇到机会才爆发**



# (四)记录点📌
这是用来记录这学期的关键点/转折点，但之后我又想，已经过去了，也已经吸收进脑子里面了，也就不需要再抠细节了

不需要过多总结、也没什么好打鸡血的，过得舒服就行
