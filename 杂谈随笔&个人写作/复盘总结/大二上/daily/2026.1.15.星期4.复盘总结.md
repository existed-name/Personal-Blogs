## 1、DQL
### （1）排序查询
#### ①语法
```sql
# 按照指定的字段作为排序依据，根据指定排序规则排序
select 查询字段 from 表名 order by 排序依据的字段1  排序规则, 排序依据的字段2  排序规则...; 
```

#### ②排序规则
1. 升序排列（ascending）：`asc`关键字
2. 降序排列（descending）：`desc`关键字
3. 不加排序规则，默认升序排列
4. 字段1作为主要排序依据，相同时则根据字段2排序（以此类推）

#### ③MySQL存储结构： 
1. 按**聚簇索引**组织数据 
2. 聚簇索引：表的**主键**（`primary key`） →如果没有→ 读到的的**第一个非空唯一字段**（`not null`、`unique`）作为主键 →还是没有→ 创建一个对外隐藏的内部字段**`row_id`**，作为主键来构建聚簇索引 
3. 决定数据在磁盘的**储存顺序** 
 
#### ④注意
不手动设置`order by`，**不保证任何顺序**（无序、**结果不稳定**）（可能按照储存结构的索引，也就是数据储存顺序读数据，所以看起来有序） 
 

### （2）分页查询
#### ①语法
```sql 
# 从起始索引开始，每页展示指定的查询数据条数
select 查询字段 from 表名 limit 要查询的起始索引  查询数据条数; 
```

#### ②附
1. 在**逻辑上**，limit是最后执行的动作：`from` → `where` → `group by`（以及聚合函数） → `having` → `select` → `order by` → `limit`
2. 先得到`select`查询结果（可以看作一个表），查询结果的第1行即为起始索引0，再分页
3. 如果不指定`order by`那就是**（2）④**的情况，所以通常配合`order by`使用



## 3、thinking--关于完美主义
### （1）掌控心理
某课程自由组队，我这组全是懒汉（包括我，但是被各位熟人抬举成了组长），然而我想，作业总是要写的，不能你推我推他推，于是“主动”承担了每次写作业报告、PPT的重担。虽然说期间我的AI使用能力大幅度提高，但是付出了巨大的时间成本——而更深层次的是，我没有把各样作业分给组员的意思，还是认为“他们应该不会写 + 我来写比较好”。直到我终于被作业磨烂耐心，把部分任务分给其他人，我才发现，他们表面上懒散，但真正出力时比我想象的好得多。进而我挖掘出了一个缺陷：我**不放心其他人，害怕他们干不好**——那是不是拿在自己手上就可以干好了？并不是，但这是一种心理——我在<u>[11月总结](https://zhuanlan.zhihu.com/p/1978373450788794930)</u>里分析了自己偶尔的“心累无力”，而AI指出这种症状跟**掌控心理**有很大关系

而这种**掌控心理**可以很好解释一个想要“完美”的人的“步步为营”：我比较犹豫、有点追求“完美”，于是我每一步都在想怎么做到最好（最优解，尤其是做选择的时候）、会不会有不够好的地方（焦虑），导致每一步都会因为限制而迈不开、迈得小/慢


### （2）完美困境
看过一个观点：**焦虑是因为怕**，个人觉得很有道理。再和**掌控心理**联动一下：失去对生活的掌控会感觉不安全、不舒服 => 害怕这种**失控感** => 焦虑 => 必须每一步都深思熟虑，来避免未来的失控 => 进一步焦虑 => 小失误&疲劳积累/出现较大失误/外界干扰，于是整个人炸了，心力憔悴 => 转移注意力&放松/简单任务找回掌控感，才逐渐恢复。我想这个应该是**完美主义者困境**的一种解释。并且还有**自我否定**（用心的投入&失望的现实、偶尔的emo）、**纠结于过去**（当时该这样做、该选这个）等等因素


### （3）破局之道
#### ①明确需求
我在<u>[10月总结](https://zhuanlan.zhihu.com/p/1970073428670283930)</u>思考过类似的问题，一个应对方法是**抓重点**：抓住最有价值的那部分，用更少的力得到更大的收益，放弃非重点以及对琐碎细节的纠结

然而这始终还是有些抽象，我也一直在想怎么“抓重点”。首先我不再把什么事情都写进日、周总结（以前还没想到发出来），只挑真正有所收获的内容——学习内容的总结回顾、部分事情的思考感悟，并且也不需要每天都总结——不是每天都有这么多的收获，也不是所有的收获都值得写。之后我在日复一日的生活中想到，我所做的每一步可能有个“目标”，这个目标是**满足当前的需求**，而我所顾虑的正是达到目标付出的**代价**。我继续想，大部分情况的代价是完全可以承受，或者说不值一提的、可以忽略不计的，那么我只需要**明确当前的需求，然后尽管去做**，完成了，就是赚到、就是一步好棋，不需要有多的顾虑

#### ②面对焦虑
既然焦虑是因为害怕，那么就找到自己害怕/不喜欢/不想做的事，然后**面对**。知道自己在焦虑什么，也就更淡定了，再**投入行动**，渐渐地没有那么焦虑了

#### ③随心所欲
通常我会预先构思计划：先干这样，再干那样，在自己的预定轨道上、有条不紊。然而我在<u>[上个星期的总结](/杂谈随笔&个人写作/复盘总结/大二上/daily/2026.1.8.星期4.复盘总结.md)</u>指出了问题所在：万一某一步受挫，一直卡在那里，那么精力可能提前透支，停滞在这一步，或者熬到了下一步，却走不动/不想走了。于是我尝试了新的策略：**有一定自律性**、大部分事情都已知或者有过计划经验（课程进度、小练习、看书、写博客、刷博客），那么无需再构思计划，直接**凭感觉做想做的事**——想做A，就做A，想做B，就做B。进一步减小计划规定带来的被动约束感，提高主动性——都是现在就想做的事，怎么会不主动？

#### ④然而
还有很多的应对方法没有发掘，而且各种方法也未必有用，或者可以缓解“症状”，但不能根治。可能接受自己，然后尽量改变自己，就已经是一个好的结果了
