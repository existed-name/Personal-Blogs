### （3）写代码  
#### ①创建文件
当前项目 → src文件夹 → test文件夹 → java文件夹 → 创建测试类（直接在测试方法里面操作，就不用写main方法了，方便调数据、即时展示）

#### ②基础代码
```java
    @Test
    public void testUpdateNameById() throws SQLException {
        // 首先需要连接数据库
        String url = 数据库连接地址，学习阶段用的本地数据库 "jdbc:mysql://localhost:3306/数据库文件夹名称";
        String databaseUser = "数据库用户名";
        String databasePassword = "数据库密码";  // 这3个通常放在常量类/配置里面
        Connection connection = DriverManager.getConnection( url, databaseUser, databasePassword );

        // 执行SQL语句
            // 静态SQL（硬编码参数）
        String updateNameSql = "UPDATE users SET name = 'xxx' WHERE id = 1";
        Statement statement = connection.createStatement();
        int affectedRows = statement.executeUpdate( updateNameSql );
        System.out.println( affectedRows + " rows affected" );
        /*
            execute: 对于增删改，返回false;查询语句，查到了返回true，否则false；很少用
            executeUpdate: 执行增删改，返回修改的行数
            executeQuery: 执行查询，返回查到的结果
            executeBatch: 批量处理
         */

        // 最后关闭资源
        connection.close();
        statement.close();
    }
```

```java
    @ParameterizedTest // 参数化测试

        // 预编译SQL（动态传递参数），同时防止SQL注入
        String selectUserSql = "SELECT * FROM users WHERE age = ? AND userGender = ?";

        try (   // 用 try-with-resources 自动关闭资源
            Connection connection = DriverManager.getConnection( DB_URL, DB_USER, DB_PWD );
            PreparedStatement preparedStatement = connection.prepareStatement( selectUserSql )
        ) {
            // 补全SQL语句、执行
            preparedStatement.setInt( 1, userAge );        // 第1个问号
            preparedStatement.setString( 2, userGender );   // 第2个问号
            try (
                ResultSet resultSet = preparedStatement.executeQuery( selectUserSql )
                // 返回的结果集装了查到的多行数据
            ) {
                StringBuilder stringBuilder = new StringBuilder();
                // 如果确定结果只有1个，那就用 if
                while ( resultSet.next() ){
                    // resultSet 内部有一个光标( cursor )指向第1行数据【之前】（第0行）
                    // 每次 next 会判断有没有下一行数据、移动光标
                    int id = resultSet.getInt( "id" );
                    String name = resultSet.getString( "name" );
                    String password = resultSet.getString( "password" );
                    stringBuilder.append( "------" ).append( "\r\n" )
                            .append( "id: " ).append( id ).append( "\r\n" )
                            .append( "name: " ).append( name ).append( "\r\n" )
                            .append( "password: " ).append( password ).append( "\r\n" );
                }
                System.out.println( "=== 查询结果 ===" );
                System.out.println( stringBuilder.toString() );
            }
        } catch ( SQLException e ){
            // 处理异常
        }
    }
```


### （4）SQL注入
#### ①场景
输入用户名、密码进行登录

#### ②sql源码
根据输入的用户名、密码查询用户，用户名、密码都正确 => 查到该用户（查询成功） => 登录
```java
String sql = "select * from users where username = '"	// 1个单引号
	 + 输入的用户名 +
	 "' and password = '"	// 双引号字符串，里面装单引号包裹输入内容(左右各1个)
	 + 输入的密码
	 + "'";​	// 1个单引号
```

#### ③例子
输入小明、123456得：`Where username = '小明' and password = '123456';​`

#### ④SQL注入
输入aaa、`' or '1' = '1` 得：`Where username = 'aaa' and password = '' or '1' = '1';`也就是补齐了password右边的一对单引号、末尾的一对单引号

由于`​A and B or C` <=> `( A and B ) or C`，于是这里 `( xxx ) or ( '1' = '1' )` 就始终为true（and优先级 > or，相当于or把左右分成2部分），就查询成功
