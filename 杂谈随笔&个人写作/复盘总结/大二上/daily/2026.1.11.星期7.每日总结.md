## 1、继续学SQL--数据查询语言
### （1）基本查询（没有查询条件）  
```
# 展示表格中的字段1、2...部分内容
select 字段1, 字段2.. from 表名;
<=>  
select 表名.字段1, 表名.字段2.. from 表名;
# 表名.字段	用于多表访问字段时，告诉MySQL访问的哪个表（但是依然要加上 from 表名）


# 展示表格的所有字段的数据
select * from 表名;


# 将字段名临时换成别名来展示数据
# 比如 name as 姓名 => 展示数据时 name 换成 '姓名'
select 字段1 as 别名1, 字段2 as 别名2... from 表名;
# as 可以省略
# 别名通常用单引号包裹（也可以双引号），不含有特殊字符（空格）时可以不带引号

# 也可以替换表名
select A.字段1, A.字段2... B.字段1, B.字段2... from 表名1 as A, 表名2 as B;


# 去重
select distinct 字段1, 字段2... from 表名;
# 但注意：distinct 限制的是[ 字段1, 字段2... ]这个整体，当这个整体出现一样的情况时，才会去重
# 逗号在编程语言中相当于&&，把各个字段用逗号连起来 => &&串起来成整体 => 筛选整体
```  


### （2）条件查询  
#### ①通式
`select xxx from 表名 [where 条件];`

#### ②逻辑运算符
**[1]** 跟编程语言一样的 `>`、`<`、`>=`、`<=`；主要看不一样的👇  

**[2]** 相等是**1个等号**（`=`）而不是2个等号（`==`）  

**[3]** 不相等：`!=`或者`<>`（**可以大于、可以小于、就是不能等于**；另外为了兼容，通常用这个）  

**[4]** `between and`闭区间：`where id between a and b;` <=> `a <= id && id <= b;`  

**[5]** `in( ... )`逐个匹配：`where id in( a, b, c... );` <=> `id = a || id = b || id = c...`  

**[6]** `like`模糊匹配：`select ... where 字段名 like str`​  

**<1>** 用来查找当 **`字段 = str`** 时的数据​  

**<2>**`like`是为字符串设计的，`str`为数值类型时（整数、小数），会被转换成字符串​

**<3>**`str` = 固定字符串、通配符`%`和占位符`_`的组合  
**A.** 通配符`%`：把一连串字符（包括空字符串）看作整体，用`%`表示​  
**B.** 占位符`_`：把任意一个字符表示成`_`​  
**C.** `where name like str`  
**Ca.** `str` = `'李%'` => 匹配有没有name = `'李'` + 一个字符串​  
**Cb.** `'%李'`、`'%李%'`同理​  
**Cc.** 如果要搜索的name包含百分号，那么用转义字符 `\%` 表示百分号 => `like '%\%%'` ​  
**Cd.** `'李_'`（1个下划线） = `'李'` + 1个任意字符  

#### ③比较运算符
**[1]**`&&`、`and` 并且  
**[2]**`||`、`or` 或者  
**[3]**`!`、`not` 非  

#### ④个人理解
**[1]** 首先明确：布尔值/逻辑真值通常是`true/false`，但SQL中还多了一个`unknown`（未知真假）；`null`是一种特殊标记，表示缺失/未知  

**[2]** ​逻辑运算符，是对逻辑真值的运算。但注意涉及`unknown`时逻辑结果不一定是`unknown`：`unknown && false = false`，`unknown || true = true`  

**[3]** 比较运算符进行数值比较，返回逻辑真值：真true假false、普通比较运算符（除了`is`）在比较中`null`时通常返回`unknown`（因为`null`的数值未知）  

**[4]** `​is`是一种特殊的比较运算符，他专门判断`null`（`is null`未知/缺失）、逻辑结果（`is true/false/unknown`）   

**[5]** 而`is not null`：`not` 显然不可能否定`null`，只能否定逻辑真值，所以这里只能是一种语义化表达，实际上应该是`not ( is null )`🤔
