# 解决`.properties`中文乱码

> <u>[个人博客仓库](https://github.com/existed-name/Personal-Blogs)</u>
---

## 1、问题描述
SpringBoot项目，发现在`src/main/resources`包下的`application.properties`文件写的中文注释都变成问号了。然后再看IDEA右下角的编码，竟然是`ISO-8859-1`（然而其他文件都默认`UTF-8`）。于是询问AI解决方法  
![一片问号](/assets/images/问题排查/开发工具与IDE/IDEA/文件编码/解决.properties文件中文乱码问题/01-GarbledCode.png "一片问号")  


## 2、解决方法
左上角菜单栏 → `File` → `Settings` → `Editor` → `File Encodings` → 在下面找到`Default encoding for properties files`，改为 UTF-8，并勾选旁边的`Transparent native-to-asci conversion`
![修改设置](/assets/images/问题排查/开发工具与IDE/IDEA/文件编码/解决.properties文件中文乱码问题/02-Settings.png "修改设置")  

然而`properties`确实显示是`UTF-8`编码了，但还是有问号

于是右键`application.properties`文件 → `Local History` → `Show History`查看文件修改记录  
![查看文件历史记录](/assets/images/问题排查/开发工具与IDE/IDEA/文件编码/解决.properties文件中文乱码问题/03-CheckHistory.png "查看文件历史记录")  
然而只看到一片问号😅怪不得之前写中文注释时，编译器冒黄提醒我……  
![还是一片问号](/assets/images/问题排查/开发工具与IDE/IDEA/文件编码/解决.properties文件中文乱码问题/04-GarbledCodeAgain.png "还是一片问号")  


## 3、总结
（1）为了避免乱码，需要及时把`properties`改为`UTF-8`编码

（2）弃坑`.properties`文件，改用`.yaml`/`.yml`文件  
![层级更清晰了](/assets/images/问题排查/开发工具与IDE/IDEA/文件编码/解决.properties文件中文乱码问题/05-FromPropertiesToYaml.png "层级更清晰了")
