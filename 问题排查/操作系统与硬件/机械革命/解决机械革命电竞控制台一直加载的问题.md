# 解决`机械革命电竞控制台`一直加载的问题

---

## 1、问题描述
24年趁国补买的鸡哥耀世15Pro，然而用了几个月那个`电竞控制台`就卡住了，在它的首页一直加载，各种功能也点不动。当时还试了网上的一些方法，但是没成功，一直放着没管它，今天折腾半天终于弄好了

## 3、其他方法
### (1)
* 按 `Win + R` 键，输入 `services.msc` 回车，打开“服务”窗口

* 往下找到 `GCUBridge`

* 确保状态是`启动`、启动类型是`自动`(右键 → `属性`里面设置)
![](/assets/images/问题排查/操作系统与硬件/机械革命/解决机械革命电竞控制台一直加载的问题/07-ServiceStatus.png "")  


### (2)
* `Ctrl + Shift + Esc`打开任务管理器

* `进程`搜索`gcu`，看到`GCUBridge`、`GCUService`，右键`结束任务`(停止/启动`GCUBridge`会自动停止/启动`GCUService`)

* `启动应用` → 找到`ControlCenterTray`(带了机械革命的logo)，启用——这个其实是开机自启动；然后系统设置 → `应用` → `启动`一样的效果
![](/assets/images/问题排查/操作系统与硬件/机械革命/解决机械革命电竞控制台一直加载的问题/08-AutoStart.png "")  

* 然后重新打开`机械革命电竞控制台`


### (3)
* 进入目录`C:\Program Files\OEM\机械革命电竞控制台\UniwillService`

* 找到`install.bat` → 右键`以管理员身份运行` → 运行完重启电脑，用来尝试重新注册/修复服务组件

* 然而我多次运行，第1次显示我这个软件已安装，之后直接闪过


### (4)
* 开始菜单栏 → 搜`机械革命电竞控制台` → `应用设置` → `修复` → 也没用(不过没有试`重置`)
![](/assets/images/问题排查/操作系统与硬件/机械革命/解决机械革命电竞控制台一直加载的问题/09-AppSetting.png "")  
![](/assets/images/问题排查/操作系统与硬件/机械革命/解决机械革命电竞控制台一直加载的问题/10-Fix.png "")  


### (5)
* `Windows 安全中心` → `病毒和威胁防护` → 下面`病毒和威胁防护设置`那里点击`管理设置` → 下面`排除项` → 点击`添加或删除排除项` → 点击`添加排除项` → `文件` → 把 `GCUBridge.exe`、`GCUService.exe` 的路径添加进来


### (6)
参考: <u>https://www.everything411.top/posts/patch-mechrevo-gcuservice.html</u>

从参考文章里面下载大佬修复的`GCUService`，重启电脑、没成功

参考: <u>https://www.bilibili.com/video/BV1M2vPzcET2/?spm_id_from=333.337.search-card.all.click</u>
